# mod-112-consulting-craft-and-communication: Consulting Craft — Executive Communication and Iteration Rhythm

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 16 hours

## Learning objectives

- Engineer demos for executive audiences — the 'start from the customer's problem' narrative shape, the 'show the before / show the after' structure, the 'what-does-the-SME-say' third-party credibility hook; staging and failure-recovery craft; the no-fake-demo rule
- Author the exec brief — the one-pager a VP reads before the meeting (problem, pilot shape, current state, what's needed), the five-minute standup narrative, the before-after KPI table
- Run the weekly / fortnightly pilot review with the customer — standing agenda, status (green / yellow / red with rationale), decisions required, open risks, metric updates
- Handle customer-side resistance — the SME who prefers their legacy workflow, the department that views the pilot as a threat, the IT review that feels adversarial; the FDE's stance of radical transparency + pragmatic respect
- Scope with discipline — say no, say 'later', say 'the applied-ai-engineer in your org can own this after hand-off'; map new asks to the pilot's success criteria; pre-empt scope creep with a decision log the customer countersigns
- Knowledge transfer to the customer's engineering team — pair-programming cadence, documentation craft, deployment runbook walkthroughs, on-call shadowing; the FDE's goal is to become unnecessary at hand-off
- Position against adjacent customer-facing roles — the FDE is not the AE, not the SE/pre-sales, not the CSM, not the implementation consultant — and keep the scope honest
